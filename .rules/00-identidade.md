# Identidade visual Cordel

Guia do visual do Voz (spec 0002) para usar em outros projetos. Inspiração: capa de folheto de cordel e xilogravura nordestina, em versão limpa e atual. Papel quente, traço preto firme, vermelho de carimbo, sombra deslocada no lugar de sombra difusa.

Código de referência: `web/src/styles/tokens.css`, `web/src/styles/index.css` e `web/src/components/ui/`.

Este diretório (`.rules/`) é a versão separada por tema do guia. Cada arquivo cobre uma parte; o `CLAUDE.md` da raiz importa todos.
